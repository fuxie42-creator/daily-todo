# 每日待办 · 可复盘清单 · 知识点库

一个单文件的纯前端待办 / 复盘 / 知识点记录应用，双击即可在浏览器中使用，无需安装、无需后端。

## 使用方式

- 在线访问：开启 GitHub Pages 后直接打开仓库 Pages 地址
- 本地使用：把 `index.html` 下载到本地，双击用浏览器打开

## 功能

- 每日待办清单，按日归档
- 中断原因分类记录（番茄钟专注 / 借助 AI 工具 / 请教他人 / 会议推进 / 碎片时间处理）
- 每日复盘笔记与标签（Python / 深度学习 / 剪辑 / 文案 / 工具技巧）
- 知识点问答库，按基础层 / 进阶层 / 场景与架构层 / 八股题 / 项目题分类
- 数据持久化在浏览器 `localStorage`，不上传服务器；清缓存会丢失，重要内容建议自行导出

## 说明

- 单文件实现，HTML + CSS + 原生 JS，无任何外部依赖与网络请求
- `localStorage` key：`todo.daily.v2`
